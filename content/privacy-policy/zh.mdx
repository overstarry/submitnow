# 隐私政策

本隐私政策说明了您在使用 submitnow 时，我们会收集哪些信息、如何使用这些信息以及与哪些第三方共享（如适用）。

## submitnow 提供的服务

submitnow 是一个开源 Web 工作台与工具箱，用于协助校验密钥文件、导入 Sitemap 并向 `api.indexnow.org` 或指定 IndexNow 参与搜索引擎端点（Bing、Yandex、Seznam.cz、Naver、Yep）批量提交 URL。本站不提供用户账户体系。

## 您主动提供的信息

### IndexNow 提交、密钥校验与远程 Sitemap 抓取

当您发起提交或使用服务端辅助检测功能时，您可能会填写：
- IndexNow key 以及可选的 `host`、`keyLocation` 与目标提交端点
- URL 列表（单批最多 10,000 条，超出时由前端自动顺序分批）
- 使用可选远程抓取功能时提供的公网 Sitemap 地址或域名

上述信息仅在服务端内存中用于执行您请求的公网密钥校验、Sitemap 读取或 IndexNow 请求转发，不会写入任何应用数据库。

### 浏览器本地工具与可选本机存储

密钥生成器、URL 规范化、批次整理器、本地 XML Sitemap 对比与代码生成器均完全在您的浏览器内运行，输入不会上传至服务器。

若您主动启用“记住站点配置”、保存 Sitemap 基线或使用本地提交历史（每条记录最多保留 200 条 URL 用于一键重载，历史中不保存密钥），相关数据仅存放在您当前设备的浏览器 `localStorage` 中，随时可在页面一键清空。

### 订阅邮件（Newsletter）

如果您订阅邮件通知，您需要提供邮箱地址。我们会使用该邮箱向您发送更新，并通过带签名的退订链接管理您的退订请求。

## 自动收集的信息

当您使用本站时，我们可能会收集：
- 基础请求元信息（例如 IP 地址、User-Agent），用于安全防护、限流防滥用与排障
- 粗粒度使用统计数据（例如页面访问与按钮触发次数；绝不将您的密钥、主机名或 URL 发送至统计埋点）
- 保存在您设备上的偏好信息（例如语言、主题设置）

## Cookies 与类似技术

我们会使用 Cookie 和/或本地存储保存语言偏好、语言提示关闭状态、深浅色主题及您主动开启的本地站点配置/历史。生产环境可能根据部署配置加载统计或广告脚本。

## 信息共享

为提供服务，我们仅在必要范围内与以下对象交互：
- IndexNow 目标端点（`api.indexnow.org`、Bing/Microsoft、Yandex、Seznam.cz、Naver 或 Yep）：按您的选择转发提交请求
- 目标公网站点：执行密钥校验或远程 Sitemap 抓取时向您指定的公网地址发起 HTTP 请求
- 邮件服务商：处理订阅邮件发送与退订管理
- 统计与广告服务商：生产环境可能按配置加载对应脚本
- 法律与安全：依法定要求或防止服务滥用时必要披露

## 数据保留

- IndexNow 提交、密钥校验与远程 Sitemap 输入：仅在内存中临时处理，不落库存储
- 订阅邮箱：在您退订前保留（或由我们主动删除）
- 限流防滥用计数：基于 IP 的滑动窗口计数仅作短期保留
- 浏览器本地存储：仅保留在您的设备上，直到您在页面或浏览器中清除

## 您的选择

您可以：
- 通过任意邮件中的签名退订链接取消订阅
- 在页面内直接删除已保存的站点配置、Sitemap 基线或提交历史
- 通过浏览器设置管理 Cookie 与本地存储

## 联系方式

如有隐私相关问题，请通过页脚展示的邮箱或源码仓库与我们联系。

## 政策更新

我们可能会不时更新本政策。请定期查看。
