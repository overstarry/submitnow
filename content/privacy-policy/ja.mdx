# プライバシーポリシー

本プライバシーポリシーでは、submitnow の利用時に当社が収集する情報、利用目的、必要に応じた第三者提供について説明します。

## submitnow の提供内容

submitnow は、IndexNow プロトコルを利用して Bing の IndexNow エンドポイントへ URL を送信するための Web UI です。本サービスはユーザーアカウント機能を提供しません。

## お客様が提供する情報

### IndexNow 送信データ

送信時に、お客様は以下を入力する場合があります：
- IndexNow key
- URL リスト（1 回あたり最大 10,000 件）
- 任意の `host` と `keyLocation`

当社はこれらの情報を用いてリクエストを生成し、Bing に送信します。IndexNow の入力内容をアプリケーションのデータベースに保存しません。

### Newsletter

ニュースレターを購読する場合、メールアドレスを提供いただきます。当社は配信および購読管理（解除を含む）のために利用します。

## 自動的に収集される情報

当社は以下の情報を自動的に収集する場合があります：
- セキュリティ/不正防止/障害対応のための基本的なリクエスト情報（IP アドレス、User-Agent など）
- サイト利用状況の分析情報（ページビュー、端末/ブラウザ情報など）
- 端末内に保存される設定情報（言語、テーマなど）

## Cookie 等の利用

当社は、言語やテーマなどの設定を保持するために Cookie および/またはローカルストレージを利用します。運用環境では、構成により解析や広告スクリプトが読み込まれる場合があり、これらが Cookie 等を利用する可能性があります。

## 第三者提供

サービス提供に必要な範囲で、当社は以下の第三者に情報を提供する場合があります：
- Bing / Microsoft：IndexNow リクエストは Bing IndexNow エンドポイントへ送信されます
- メール配信事業者：ニュースレターの配信および購読管理
- 解析/広告事業者：運用環境で解析や広告スクリプトが読み込まれる場合があります
- 法令等：法令遵守または不正防止のために必要な場合

## 保管期間

- IndexNow の入力内容：リクエスト送信処理のために利用し、アプリケーションのデータベースには保存しません
- Newsletter のメールアドレス：購読解除まで（または当社が削除するまで）
- 不正防止データ：レート制限を有効にしている場合、一定期間保持されることがあります
- 解析データ：各事業者の設定に従います

## お客様の選択

お客様は以下を行うことができます：
- 受信メール内の解除リンクからニュースレターを解除する
- ブラウザ設定で Cookie/ローカルストレージを管理する（無効化すると一部の設定保持が動作しない場合があります）
