# 关于 submitnow

**submitnow**（`https://www.submitnow.dev`）是一个面向**独立开发者、技术 SEO 工程师、程序化 SEO 团队与站点管理员**的**永久免费、MIT 开源、隐私优先的 IndexNow Web 工作台、浏览器工具箱与本地 CLI / MCP Server**。无需注册账号，也不在服务端落库保存密钥或 URL，submitnow 支持提交前公网密钥体检、在线 Sitemap 增量提取与超 10,000 条自动分批推送，一次通知触达 Bing（支撑 Microsoft Copilot 与 ChatGPT Search）、Yandex、Seznam.cz、Naver 和 Yep。

想评估 submitnow 与同类工具的差异，或核对免费托管限流与自托管能力？可查看 [IndexNow 工具横向对比](/compare) 与 [定价、免费配额与自托管说明](/pricing)。

## 为什么 IndexNow 对传统搜索与 AI 搜索同样关键

传统被动抓取往往需要数天甚至数周才能发现深层页面变更。通过 IndexNow，站点只需向 `api.indexnow.org`（或任一参与引擎端点）发送一次请求，通知就会同步至 **Bing、Yandex、Seznam.cz、Naver 和 Yep**。由于 Bing 索引同时支撑 **Microsoft Copilot** 并直接影响 **ChatGPT Search** 的网页检索，及时推送变更能够明显缩短内容在传统搜索与 AI 搜索中的发现延迟。

## 本站提供的核心能力

- **多端点批量提交**：支持切换 `api.indexnow.org`、Bing、Yandex、Seznam.cz、Naver、Yep；超过 10,000 条 URL 自动按批顺序提交。
- **在线 Sitemap 与嵌套 Index 拉取**：支持直接抓取公网 `sitemap.xml`、`.xml.gz` 以及嵌套 `<sitemapindex>`，并可按 `lastmod`（近 24 小时 / 7 天 / 30 天）筛选增量页面。
- **提交前密钥文件体检**：从公网验证 `<key>.txt` 是否存在 404、软 404 HTML、UTF-8 BOM、跨主机跳转或内容不完全匹配等问题。
- **六款浏览器端配套工具**：密钥生成器、密钥校验器、URL 规范化、批次整理器（自动按域名与 10,000 条切片）、Sitemap 对比（新增 / 变更 / 已删除）以及代码生成器（`curl` / JavaScript / Python / Go / GitHub Actions / JSON）。
- **开发者自动化**：仓库内置零依赖的本地 CLI 与轻量 MCP Server，可直接接入终端脚本、CI/CD 流水线与 AI 编程助手。

## 参考请求

```bash
curl -X POST "https://api.indexnow.org/indexnow" \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "host": "www.example.com",
    "key": "your-indexnow-key",
    "keyLocation": "https://www.example.com/your-indexnow-key.txt",
    "urlList": [
      "https://www.example.com/page-1",
      "https://www.example.com/page-2"
    ]
  }'
```

## 隐私与安全设计

- **免注册、服务端零持久化**：提交的密钥、URL 与远程抓取的 Sitemap 仅在内存中处理转发，不落库、不留存。
- **纯本地可选保存**：多站点 Profile、Sitemap 基线快照和可导出的 CSV/JSON 历史记录仅存放在当前浏览器的 `localStorage` 中。
- **出站请求安全防护**：服务端密钥校验与远程 Sitemap 抓取均具备 SSRF 防护（拦截私网/保留地址、元数据地址及不安全跳转）与按 IP 维度的限流保护。
