# submitnow について

**submitnow**（`https://www.submitnow.dev`）は、**個人開発者・テクニカル SEO エンジニア・プログラマティック SEO チーム・サイト運営者**に向けた、**永久無料・MIT オープンソース・プライバシー重視の IndexNow Web ワークベンチ、ブラウザ完結型ツール集、ローカル CLI / MCP サーバー**です。アカウント登録不要・サーバー非保存のまま、キーファイルの事前診断、公開サイトマップの差分抽出、10,000 件超の自動分割送信を実行し、Bing（Microsoft Copilot・ChatGPT Search の発見基盤）、Yandex、Seznam.cz、Naver、Yep へ更新を通知します。

他ツールとの比較や無料枠・セルフホストの詳細は、[IndexNow ツール徹底比較](/compare) と [料金・無料クォータ・セルフホスト](/pricing) をご覧ください。

## 検索エンジンと AI 検索において IndexNow が重要な理由

従来のクロール待ちでは、新しいページや更新内容の発見に数日から数週間かかることがあります。IndexNow で `api.indexnow.org`（または参加検索エンジンのエンドポイント）へ 1 回通知するだけで、**Bing・Yandex・Seznam.cz・Naver・Yep** へ自動的に共有されます。Bing のインデックスは **Microsoft Copilot** の基盤であり **ChatGPT Search** の Web 検索にも深く関わるため、タイムリーな通知は従来の検索と AI 検索双方の発見遅延を短縮します。

## 主な機能

- **マルチエンドポイント一括送信**：`api.indexnow.org`、Bing、Yandex、Seznam.cz、Naver、Yep を選択可能。10,000 件を超える URL リストも自動的に分割して順次送信します。
- **公開サイトマップ・サイトマップインデックス取得**：公開中の `sitemap.xml`、`.xml.gz`、ネストされた `<sitemapindex>` を直接取得し、`lastmod`（24 時間 / 7 日 / 30 日）で更新ページのみを抽出できます。
- **送信前キーファイル診断**：404、ソフト 404 の HTML 応答、UTF-8 BOM、別ホストへのリダイレクト、本文不一致を公開インターネット側から事前検知します。
- **6 つのブラウザ完結型ツール**：キー生成、キー検証、URL 正規化、バッチ整理（ホスト別・10,000 件単位分割）、サイトマップ差分比較（追加・更新・削除）、コード生成（`curl` / JavaScript / Python / Go / GitHub Actions / JSON）。
- **開発者向け自動化**：リポジトリ内に依存関係ゼロのローカル CLI と軽量 MCP サーバーを同梱し、ターミナル作業や AI コーディングエージェントから直接利用できます。

## リクエスト例

```bash
curl -X POST "https://api.indexnow.org/indexnow" \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "host": "www.example.com",
    "key": "your-indexnow-key",
    "keyLocation": "https://www.example.com/your-indexnow-key.txt",
    "urlList": [
      "https://www.example.com/page-1",
      "https://www.example.com/page-2"
    ]
  }'
```

## プライバシーとセキュリティ

- **アカウント不要・サーバー保存なし**：送信したキーや URL、取得したサイトマップはメモリ上でのみ処理し、サーバー側には一切保存しません。
- **端末内のみの任意保存**：複数サイトのプロファイル、サイトマップ基準スナップショット、CSV/JSON 出力対応の送信履歴はブラウザの `localStorage` のみに保存されます。
- **安全な外部取得**：サーバー側のキー検証とサイトマップ取得には、プライベート IP や危険なリダイレクトを遮断する SSRF 対策および IP 単位のレート制限を実装しています。
