# submitnow について

submitnow は、IndexNow プロトコルを使って Bing に URL をまとめて送信するための軽量 Web UI です。

## IndexNow の要件

IndexNow を使うには以下が必要です：

1. IndexNow key
2. サイト上で公開されている key ファイル：
   - URL: `https://<host>/<key>.txt`
   - 内容: key のみ（プレーンテキスト）

その後、Bing にバッチリクエストを送信できます：

```bash
curl -X POST "https://www.bing.com/indexnow" \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "host": "www.example.com",
    "key": "your-indexnow-key",
    "keyLocation": "https://www.example.com/your-indexnow-key.txt",
    "urlList": [
      "https://www.example.com/page-1",
      "https://www.example.com/page-2"
    ]
  }'
```

## このサイトの使い方

- URL（1 行に 1 件）を貼り付けて key を入力します。
- 必要に応じて `host` と `keyLocation` を指定します。
- 送信すると、サーバー側から Bing にリクエストを送ります。

## 制限

- 現在は Bing エンドポイントのみ対応です。
- 永続化は行いません（入力内容は保存しません）。
