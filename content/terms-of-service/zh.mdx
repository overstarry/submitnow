# 服务条款

欢迎使用 submitnow。访问或使用本网站即表示您同意本服务条款。

## 1. 服务内容

submitnow 提供免费的 Web 界面与开源辅助工具，用于校验 IndexNow 密钥文件、导入公网 XML Sitemap 以及向 `api.indexnow.org` 或参与搜索引擎端点（Bing、Yandex、Seznam.cz、Naver、Yep）转发 IndexNow 提交请求。本站不提供用户账户体系。

## 2. 您的责任

您同意：
- 仅针对您拥有或获得授权管理的域名、密钥文件、Sitemap 与 URL 执行校验、抓取或提交
- 提供准确的参数信息（如 `host`、`key`、`keyLocation` 与 `urlList`）
- 遵守适用法律以及 IndexNow 协议和各参与搜索引擎的使用规范

## 3. 禁止行为

您不得：
- 以自动化洪泛等方式干扰服务或试图绕过限流机制
- 利用密钥校验或远程 Sitemap 抓取功能探测非公开网络、内网地址或未授权第三方基础设施
- 将服务用于任何违法、有害或欺诈性用途

## 4. 第三方服务

当您发起 IndexNow 提交时，我们会按您的选择将请求转发至对应端点（`api.indexnow.org`、Bing、Yandex、Seznam.cz、Naver 或 Yep）。第三方搜索引擎及已启用的邮件、统计或广告服务商均按其各自条款与政策处理数据。

## 5. 服务可用性与变更

我们可能随时修改、限流、暂停或终止部分或全部服务，并可能不时更新本条款。

## 6. 免责声明

本服务按“现状”和“可用”提供，不作任何形式的保证。我们不保证您提交的 URL 一定会被任何搜索引擎或 AI 搜索服务抓取、受理或收录。

## 7. 责任限制

在适用法律允许的最大范围内，我们不对因使用本服务而产生的任何间接、附带、特殊、后果性或惩罚性损害承担责任。
