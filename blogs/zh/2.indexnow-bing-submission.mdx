## IndexNow（Bing）是什么？

IndexNow 允许你主动通知搜索引擎 URL 的新增、更新或删除。本站当前仅对接 Bing 的 IndexNow 端点。

## 前置条件

你需要：

- 一个 IndexNow key
- 在你的网站上公开可访问的 key 文件

## 1）托管 key 文件

key 文件必须能通过下面的 URL 访问到：

```
https://<host>/<key>.txt
```

文件内容必须只包含 key 本身（纯文本）：

```
<key>
```

## 2）提交 URL

提交时，URL 需要满足：

- 必须是合法的 `http(s)` URL
- 必须属于同一个 hostname

你可以使用本站 UI，也可以直接发送请求：

```bash
curl -X POST "https://www.bing.com/indexnow" \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "host": "www.example.com",
    "key": "your-indexnow-key",
    "keyLocation": "https://www.example.com/your-indexnow-key.txt",
    "urlList": [
      "https://www.example.com/page-1",
      "https://www.example.com/page-2"
    ]
  }'
```

## 常见错误

- **403**：key 无效，或 key 文件不可访问
- **422**：URL 列表无效，或 URL 与 host 不匹配
- **429**：被限流，请稍后重试

## 建议

- 单次请求只提交一个站点（不要混合多个 host）。
- 保证 `keyLocation` 的 hostname 与提交的 host 一致。
- 先用少量 URL 做一次验证，再扩大批量。
