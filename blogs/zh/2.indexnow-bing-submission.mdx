## IndexNow（Bing）是什么？

IndexNow 允许你主动通知参与搜索引擎 URL 的新增、更新或删除。通过 `api.indexnow.org` 或 Bing 端点提交一次，即可同步触达 Bing（支撑 Microsoft Copilot 与 ChatGPT Search）、Yandex、Seznam.cz、Naver 和 Yep。

## 前置条件

你需要：

- 一个 IndexNow key
- 在你的网站上公开可访问的 key 文件

## 1）托管 key 文件

key 文件必须能通过下面的 URL 访问到：

```
https://<host>/<key>.txt
```

文件内容必须只包含 key 本身（纯文本）：

```
<key>
```

## 2）提交 URL

提交时，URL 需要满足：

- 必须是合法的 `http(s)` URL
- 必须属于同一个 hostname

你可以使用本站 UI，也可以直接发送请求：

```bash
curl -X POST "https://www.bing.com/indexnow" \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "host": "www.example.com",
    "key": "your-indexnow-key",
    "keyLocation": "https://www.example.com/your-indexnow-key.txt",
    "urlList": [
      "https://www.example.com/page-1",
      "https://www.example.com/page-2"
    ]
  }'
```

## 常见错误

- **[403](/zh/docs/status-codes/403)**：key 无效，或 key 文件不可访问 —— 可使用 [IndexNow 密钥校验器](/zh/tools/indexnow-key-checker) 排查
- **[422](/zh/docs/status-codes/422)**：URL 列表无效，或 URL 与 host 不匹配 —— 可使用 [URL 批次整理器](/zh/tools/indexnow-batch-builder) 按主机名分组
- **[429](/zh/docs/status-codes/429)**：被限流，请稍后重试 —— 可使用 [Sitemap 对比工具](/zh/tools/sitemap-diff) 仅提交增量页面

## 建议

- 单次请求只提交一个站点（不要混合多个 host）。
- 保证 `keyLocation` 的 hostname 与提交的 host 一致。
- 先用少量 URL 做一次验证，再扩大批量；更多排错细节可查看完整 [IndexNow 文档](/zh/docs) 与 [免费工具集](/zh/tools)。
