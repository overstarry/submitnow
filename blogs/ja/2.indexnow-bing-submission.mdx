## IndexNow（Bing）とは

IndexNow は、URL の追加・更新・削除を参加検索エンジンへ能動的に通知する仕組みです。`api.indexnow.org` または Bing へ 1 回送信するだけで、Bing（Microsoft Copilot・ChatGPT Search 基盤）、Yandex、Seznam.cz、Naver、Yep へ共有されます。

## 前提

必要なもの：

- IndexNow key
- サイト上で公開されている key ファイル

## 1) key ファイルを公開する

key ファイルは次の URL でアクセスできる必要があります：

```
https://<host>/<key>.txt
```

内容は key のみ（プレーンテキスト）：

```
<key>
```

## 2) URL を送信する

送信する URL は以下を満たしてください：

- 有効な `http(s)` URL
- すべて同一 hostname

この UI を使うか、次のように直接送信できます：

```bash
curl -X POST "https://www.bing.com/indexnow" \
  -H "Content-Type: application/json; charset=utf-8" \
  -d '{
    "host": "www.example.com",
    "key": "your-indexnow-key",
    "keyLocation": "https://www.example.com/your-indexnow-key.txt",
    "urlList": [
      "https://www.example.com/page-1",
      "https://www.example.com/page-2"
    ]
  }'
```

## よくあるエラー

- **[403](/ja/docs/status-codes/403)**：key が無効、または key ファイルにアクセスできない — [IndexNow キーファイル検証ツール](/ja/tools/indexnow-key-checker) で確認できます
- **[422](/ja/docs/status-codes/422)**：URL リストが無効、または URL が host と一致しない — [URL バッチ整理ツール](/ja/tools/indexnow-batch-builder) でホスト別に整理できます
- **[429](/ja/docs/status-codes/429)**：レート制限、しばらくして再試行 — [サイトマップ差分ツール](/ja/tools/sitemap-diff) で変更 URL のみ送信しましょう

## ヒント

- 1 回のリクエストは 1 ホストのみ（複数 host を混在させない）。
- `keyLocation` の hostname と送信する host を一致させる。
- まず少数の URL で動作確認してから件数を増やしてください。詳しい手順は [IndexNow ドキュメント](/ja/docs) と [無料ツール一覧](/ja/tools) を参照してください。
