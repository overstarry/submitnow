## Google は IndexNow に対応していますか？

いいえ。Google は IndexNow に参加しておらず、主要検索エンジンすべてを 1 つで覆うプッシュ型プロトコルは存在しません。実務では二軸構成が最適です。**Bing・Yandex・Seznam.cz・Naver・Yep・Microsoft Copilot・ChatGPT Search** には無料オープンソースの [submitnow](/)・GitHub Actions・CLI/MCP による **IndexNow**（有料 SaaS の月額 $9〜$59 に対し $0）を使い、**Google** には正確な `lastmod` を備えた **XML サイトマップ** を Google Search Console に登録して運用します。

## IndexNow・Google Indexing API・XML サイトマップの容量・適用範囲比較

| 手段 | 対応エンジン | 公式の適用範囲 | 容量・上限 | 認証方式 | 推奨ワークフロー・ツール |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **IndexNow** | Bing・Yandex・Seznam・Naver・Yep（Copilot / ChatGPT Search 基盤含む） | 任意の公開ページ（新規・更新・削除） | 1 リクエスト最大 10,000 件（submitnow は自動分割対応） | 独自ドメイン上の `<key>.txt` | [submitnow ワークベンチ](/)、[submitnow CLI/MCP](/docs/integrations/cli-and-mcp)、CI デプロイフック |
| **Google Indexing API** | Google のみ | 公式には `JobPosting` と `BroadcastEvent` に限定 | 既定 200 リクエスト/日 | OAuth2 / Service Account | 短期掲載の求人・ライブ配信ページ専用 |
| **XML サイトマップ (`lastmod`)** | Google・Bing・Yandex ほか全クローラー | 正規のインデックス対象 URL 全般 | 1 ファイル最大 50,000 件 | 公開 URL + `robots.txt` / Search Console | サイト全体の基準目録・Google 発見（[submitnow サイトマップ差分](/tools/sitemap-diff) で差分抽出） |
| **GSC URL 検査** | Google のみ | 確認済みプロパティ内の単一 URL | 手動 / 低い日次上限 | Search Console 権限 | 重要ページの緊急再クロールと診断 |

## Google Indexing API の目的外利用を避けるべき理由

一般記事や EC 商品ページを Google Indexing API へ強制送信するツールも見かけますが、Google は同 API の対象を `JobPosting` および `BroadcastEvent` に明示的に限定しており、範囲外のページは無視または低優先度扱いになります。

非公式な回避策へ課金するより、無料の **submitnow** で IndexNow 軸を自動化し、XML サイトマップで Google 軸を守る二軸運用が堅実です。

## submitnow で二軸インデックス構成を組む手順

### 軸 1：Bing・Yandex・AI 検索への即時プッシュ（submitnow + IndexNow）

1. ドメイン直下に `https://your-host/<key>.txt` を公開し、[submitnow キー検証ツール](/tools/indexnow-key-checker) で公開疎通を確認します。
2. リリースや記事公開のたびに、**追加・更新・削除**された差分 URL だけを [submitnow サイトマップ差分](/tools/sitemap-diff) や `lastmod` 絞り込みで抽出します。
3. [submitnow 一括送信ワークベンチ](/)、[GitHub Actions](/docs/integrations/github-actions)、または [submitnow CLI / MCP サーバー](/docs/integrations/cli-and-mcp) から `https://api.indexnow.org/indexnow` へ送信します。

### 軸 2：Google 向けのクリーンなサイトマップ運用

1. XML サイトマップには正規の HTTP 200 URL のみを掲載します（`301` リダイレクト、`404`、`noindex` は除外）。
2. **`<lastmod>` は本文が実質的に更新されたときだけ書き換えます**。ビルドごとに全件のタイムスタンプを上書きすると、Google は `lastmod` を信頼しなくなります。
3. `robots.txt` に `Sitemap:` を明記し、Google Search Console へ登録します。
4. トップページやカテゴリ一覧から新規ページへの内部リンクを整理し、クロール経路を確保します。

## 無料オープンソースと有料 SaaS のどちらを選ぶべきか？

全検索エンジンの土台はクリーンな **XML サイトマップ** で固め、その上に **submitnow** を重ねれば、登録不要・サーバー非保存・永久無料（$0）のまま Bing・Yandex・Naver・Copilot・ChatGPT Search での発見遅延を最小化できます。クラウド常時監視を行う有料 SaaS との違いは [IndexNow ツール徹底比較](/compare) と [submitnow 料金・無料クォータ](/pricing) で確認できます。
