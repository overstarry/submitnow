## Does Google support IndexNow?

No — Google does not participate in IndexNow, and no single push protocol covers every search engine. Run a dual-track stack: use **IndexNow** (free via [submitnow](/), GitHub Actions, or CLI/MCP — versus $9–$59/month paid SaaS monitors) for **Bing, Yandex, Seznam.cz, Naver, Yep, Microsoft Copilot, and ChatGPT Search**, and keep a clean **XML sitemap with accurate `lastmod` timestamps** in Google Search Console for **Google**.

## Why you should avoid abusing the Google Indexing API

Many third-party "instant Google indexer" tools wire ordinary blog posts or e-commerce pages into Google's Indexing API. Google explicitly documents that the Indexing API is intended only for pages with `JobPosting` or `BroadcastEvent` structured data, and pages pushed outside that scope are routinely ignored or deprioritized.

## How do you set up a dual-track indexing architecture with submitnow?

### Track 1: Instant push for Bing, Yandex & AI Search (IndexNow via submitnow)

1. Host a single root verification file at `https://your-host/<key>.txt` and confirm it passes the [submitnow IndexNow Key File Checker](/tools/indexnow-key-checker).
2. On every deploy or content publish, isolate only **added, changed, or deleted** URLs using [submitnow Sitemap Diff](/tools/sitemap-diff) or the live `lastmod` filter.
3. Push the delta batch to `https://api.indexnow.org/indexnow` via the [submitnow Batch Submitter](/), [GitHub Actions](/docs/integrations/github-actions), or the [submitnow CLI / MCP server](/docs/integrations/cli-and-mcp).

### Track 2: Reliable discovery for Google

1. Generate accurate, canonical-only XML sitemaps (never include `301` redirects, `404`s, or `noindex` pages).
2. Update `<lastmod>` **only when main content meaningfully changes** — Google explicitly ignores `<lastmod>` if your build tool restamps every URL on every deploy.
3. Reference your sitemap index in `robots.txt` and submit it once in Google Search Console.
4. Keep strong internal linking from high-crawl pages (home, category hubs, recent posts) to new URLs.
